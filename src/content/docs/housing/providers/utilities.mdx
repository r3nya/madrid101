export const slug = (name) =>
  name
    .toLowerCase()
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '')
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/(^-|-$)/g, '');

## Как это работает

:::note
В Испании поставщика энергии (comercializadora) выбираете вы сами. При смене поставщика:
- Не нужно менять счетчики или проводку
- Подача электричества и газа не прерывается
- Процесс занимает около 15–20 дней
:::

### Типы тарифов

1. **Регулируемый тариф на электричество (PVPC)**
   - Цена меняется каждый час
   - Доступен только через comercializadoras de referencia (регулируемые поставщики), например Curenergía (группа Iberdrola), Energía XXI (Endesa), Comercializadora Regulada Gas & Power (Naturgy)
   - Только для электричества; через PVPC оформляется и bono social

2. **Регулируемый тариф на газ (TUR)**
   - Тоже существует, оформляется только через регулируемых поставщиков (COR)

3. **Свободный рынок (mercado libre)**
   - Фиксированная цена на срок контракта или другие форматы (по периодам, по рыночной цене)
   - Доступен и для электричества, и для газа
   - Все поставщики ниже, включая Octopus, работают на свободном рынке — это не PVPC/TUR и не bono social

Сравнить предложения можно в официальном [сравнителе CNMC](https://comparador.cnmc.gob.es/).

## Поставщики

Все поставщики ниже продают частным клиентам в Мадриде.

{utilityProviders.map((provider) => (
  <div key={provider.name}>
    <h3 id={slug(provider.name)}>{provider.name}</h3>
    <ul>
      {provider.bullets.map((bullet) => (
        <li key={bullet}>{bullet}</li>
      ))}
      {provider.referral && (
        <li>
          <a href={provider.referral.href}>Реферальная ссылка</a>, {provider.referral.note}
        </li>
      )}
    </ul>
    <LinkCard
      title={provider.name}
      description={provider.cardDescription}
      href={provider.url}
    />
  </div>
))}

## Необходимые документы

Для заключения контракта потребуются:
- DNI/NIE
- CUPS (уникальный код точки подключения, есть в любом счете)
- Банковские реквизиты
- Документ о праве пользования помещением (контракт аренды или документ о собственности)
