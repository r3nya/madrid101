## Виды цифровых подписей

### ACCV

ACCV (Agencia de Certificación Electrónica de la Comunitat Valenciana) – центр электронной сертификации Валенсийского сообщества. Позволяет получить сертификат **полностью онлайн** через видеоидентификацию. Срок выпуска — до **5 días hábiles**. Срок действия сертификата — **3 года**.

**Требования:**
- NIF/NIE и действующий документ с фотографией: ACCV принимает DNI, TIE/карту резидента, испанский или иностранный паспорт, испанские водительские права. Физическая TIE не обязательна для всех заявителей; бумажный NIE сам по себе не заменяет документ с фото
- Устройство с камерой
- Мобильный телефон для СМС, email и банковская карта для предавторизации оплаты

**Преимущества:**
- Не требуется личный визит в офис
- Выпуск до 5 рабочих дней
- Видеоидентификация стоит **3,40 €** по [текущим условиям ACCV](https://www.accv.es/tu-certificado/videoid/ciudadano/); перед заявкой проверьте цену

## Как получить сертификат ACCV онлайн

### Шаг 1. Подача заявки

Откройте [условия и инструкции ACCV](https://www.accv.es/tu-certificado/videoid/ciudadano/) и перейдите к заявке. Укажите NIE/NIF, согласитесь с условиями и выполните предавторизацию оплаты картой. На весь процесс, включая проверку ACCV, отведено **7 календарных дней**, поэтому начинайте видеоидентификацию сразу.

### Шаг 2. Заполнение данных

Укажите личные данные, мобильный телефон и email. Подтвердите телефон кодом из СМС и следуйте инструкциям для проверки email.

### Шаг 3. Видеоидентификация

Начните процесс видеоидентификации. Потребуется:
- Показать выбранный действующий документ с фотографией по инструкции сервиса
- Сделать селфи
- Выполнить действия по инструкции (посмотреть направо/налево, улыбнуться)
- Ввести код из СМС

Проверка может занять до **5 días hábiles**.

### Шаг 4. Генерация сертификата

После одобрения получите код генерации по СМС и скачайте сертификат на компьютер по инструкции ACCV. Код действует **15 календарных дней**. Сохраните резервную копию сертификата с паролем.

### Шаг 5. Установка

Откройте скачанный файл и установите сертификат в систему. Для проверки попробуйте авторизоваться на [сайте налоговой](https://sede.agenciatributaria.gob.es/Sede/mi-area-personal.html) через «Mis datos censales».

### FNMT

FNMT (Fábrica Nacional de Moneda y Timbre) - национальный монетный двор, выпускающий цифровые сертификаты для электронной подписи. Сертификат FNMT используется для подписи документов, отправки налоговой декларации, подачи заявлений на государственные услуги и т.д. Действителен в течение 4 лет.

Для [видеоидентификации FNMT](https://www.sede.fnmt.gob.es/en/certificados/persona-fisica/obtener-certificado-video-identificacion) нужен действующий **DNI electrónico**; цена услуги — **2,99 € + налоги**, сам сертификат бесплатный. NIE/TIE не заменяют DNI для этого способа. Иностранцам с NIE доступен [FNMT с личным подтверждением личности](https://www.sede.fnmt.gob.es/certificados/persona-fisica/obtener-certificado-software) либо ACCV при выполнении его условий.

### Cl@ve

Это система идентификации, позволяющая гражданам взаимодействовать с государственными органами онлайн.
- **Cl@ve PIN** – временный пароль, который вы получаете из приложения
- **Cl@ve Permanente** – постоянный пароль, который вы создаете самостоятельно; действует **2 года**
- **Cl@ve Móvil** – подтверждение через мобильное приложение, сосканировав QR-код

### Что лучше?

- Если вам нужен высокий уровень безопасности для юридически значимых документов (например смены данных), FNMT может быть предпочтительнее.
- Если вам нужен простой доступ к госуслугам онлайн, Cl@ve более удобен.
